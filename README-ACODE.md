# EarnX — Acode Web Source

This package contains the editable web source for EarnX:
- HTML pages
- CSS styles
- JavaScript files
- Firebase web configuration/code
- PWA manifest

Open the extracted folder in Acode and edit the `.html`, `.css`, and `.js` files.

Important: Acode is an editor/preview environment. Production Firebase rewards, AdMob rewarded ads/SSV, Cloud Functions, authentication, and withdrawals still require their real backend configuration and cannot be made real by editing frontend files alone.

For local preview, use Acode's web preview. If browser security blocks Firebase modules from `file://`, preview through a local web server/preview feature rather than opening the HTML directly as a file.
